Veja antes de aplicar

No modo Sugerir, o resultado chega em tempo real num painel ao lado do texto. Peça um ajuste em “Refinar” (mais curto, mais formal) e só aplique quando estiver bom. Para código, o resultado aparece colorido como num editor.

Feito para o seu jeito de escrever

As extensões são seus próprios prompts. O improve vem com quatro de exemplo, e você cria quantas quiser.

Extensões suas

Prompt com Markdown e variáveis como {{selection}}, ícone, modo e atalho próprio. Importe e exporte para compartilhar.

O provedor que você preferir

Anthropic, OpenAI, DeepSeek ou um modelo local no Ollama. Escolha o modelo de cada extensão.

Privado por padrão

Sem telemetria. O texto só sai do computador para o provedor que você configurou, e as chaves ficam cifradas no cofre do sistema.

Rápido como um atalho

O popup abre na hora, junto do cursor, e funciona inteiro pelo teclado. A área de transferência volta como estava.

Bom com código

Marque uma extensão como código e o resultado aparece com realce de sintaxe, no tema claro ou escuro.

Em três idiomas

Interface em português, inglês e espanhol. Tema escuro ou claro, seguindo o sistema.

No macOS e no Linux o improve ainda está em prévia: as configurações funcionam, e o atalho global com captura do texto chega nas próximas versões. No macOS, o app ainda não é notarizado pela Apple; na primeira vez, abra com o botão direito → Abrir. No Linux, instale com sudo apt install ./improve-linux-amd64.deb.
